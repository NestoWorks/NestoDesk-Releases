# NestoDesk — AI Conversation & Work History

**Don't let your AI conversations go to waste.**

NestoDesk is a local-first Windows application for searching, organizing, and reusing ChatGPT conversations and supported Codex work history.

It helps you find past research, decisions, ideas, and development work across hundreds or thousands of AI conversations — without losing their original context.

## Features

- **ChatGPT Archive** — Import ChatGPT export ZIP files and browse your conversations.
- **Full-Text Search** — Search across imported conversation history.
- **Work History** — Organize related conversations and supported Codex history by project or task.
- **Productivity Tools** — Notes, Prompt Editor, and an integrated AI Browser.

Imported conversations and primary workspace data are stored locally on your PC. The AI Browser connects to external AI services when used.

## Downloads

NestoDesk Public Preview builds will be available under **GitHub Releases**.

Download the explicitly named `NestoDesk-...-win-x64.zip` file from Release Assets.

**Platform:** Windows 11 x64

**Installation:** Extract the ZIP and run `NestoDesk.App.exe`. No installer is required.

The .NET runtime is included. The AI Browser requires Microsoft Edge WebView2 Runtime.

This application is not code-signed. Windows security features or organizational policies may warn about or block execution. Do not disable security protections to run it.

As a preview product, NestoDesk may contain bugs or incomplete features. Back up your workspace before updating.

**This is a binary distribution repository, not the NestoDesk application source repository.** GitHub-generated Source code archives contain only this repository's distribution files.
